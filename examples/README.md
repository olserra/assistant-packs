## 🎛️ Tuning recipes

Things you can say to your Instinct after installing. Each one changes one thing and keeps the rest.

| Goal | Say |
|------|-----|
| Earlier mornings on weekdays only | *"Move the morning brief to 6:30 on weekdays, keep 8:00 on weekends."* |
| A lighter brief | *"Drop markets and field news. Keep weather, priorities and the drill."* |
| Runner's weather | *"Add one line on the weather for a run at 7:00."* |
| Holiday mode | *"Pause everything until Monday, then pick up where we left off."* |
| Sick day | *"No ping today, I'm sick."* The day's target drops to 1 point. |
| A different skill to practice | *"Change my daily drill to public speaking."* |
| Only the evening plan | *"Keep just the evening brief, turn the rest off."* |
