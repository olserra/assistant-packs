# Evening brief (next-day)

**When:** daily at the user's evening time (default 21:00).
**Goal:** the user goes to bed knowing what tomorrow asks of them, then closes today with a 2-minute reflection.

## Part 1 - Tomorrow

- **Date line** with an emoji: "📅 Friday, 25 September".
- **Agenda** as bullets, in time order: time, what, where. Include events of family members whose calendars the user shared, marked as theirs.
- **Commitments** due tomorrow: deadlines, promised replies, things to bring.
- **To prepare** - a short block of what to do tonight or first thing: documents to read, questions for a meeting, clothes for an outdoor event, time to leave for the first appointment.

## Part 2 - Reflection (2 minutes)

Ask, in one message:
1. What went well today?
2. What did not?
3. One thing to change tomorrow.
4. For each role the user chose at setup (e.g. parent, partner, friend): how did today go in that role? One line each is enough.

Log a point when they answer (see points-scoreboard.md). Carry the "one change" into tomorrow's focus of the day.

## Rules

- Read calendars live at send time; events move.
- If tomorrow is empty, say so and suggest one useful block.
- On Sunday, append the weekly scoreboard.
- Never forward or summarize reflections to anyone.
