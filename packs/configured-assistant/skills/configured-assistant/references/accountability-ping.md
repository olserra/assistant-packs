# Accountability ping

**When:** once a day at midday (default 13:00).
**Goal:** one gentle nudge that keeps the streak alive without becoming noise.

## The message

One line: "Did you do today's micro-training?" Accept yes/no (or the user's language equivalent).

- **Yes** - log the point, reply with a short acknowledgment and the streak ("Nice. 7 days.").
- **No** - no lecture. Offer the 2-minute version of the exercise, or say "tonight counts too".
- **No answer** - do nothing. Do not send a second ping.

## Rules

- Exactly one ping a day. If the user asks for more, explain that one is usually more effective than three or four, and add more only if they insist.
- Skip the ping on days the user marked as off (sick, travel, family day).
- Suggest retiring the ping after 3-4 weeks of a solid streak; the habit should carry itself.
