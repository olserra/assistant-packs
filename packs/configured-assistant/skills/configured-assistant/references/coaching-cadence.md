# Coaching cadence

A light coaching layer the user opts into. It works because it is small, regular and forgiving.

## Technique of the week

- One habit technique at a time. Rotate only when it is solid, not on a fixed calendar.
- Good first technique: **two lists** - write your top 5 goals for the quarter, and a second list of tempting distractions you will avoid. It helps when anxiety makes every alternative path look better.
- Other options to rotate in: time-blocking the first hour, a weekly review, "one thing" daily priority, 2-minute rule, temptation bundling.
- Mention the technique in one line in the morning brief. Award a point when the user reports applying it.

## Daily micro-training (5 minutes)

For the skill chosen at setup. Rotate formats:
- A drill (e.g. answer three common objections in one sentence each).
- A reframe (rewrite a weak sentence into a strong one).
- A tiny study (one idea from a known book or expert, one way to use it today).
- A reflection (what worked in the last real attempt).

## Role-play on demand

When the user says "simulate a call" (or similar), play a demanding counterpart in their skill area: raise realistic objections, stay in character, then give direct, specific feedback in three bullets: what worked, what to cut, one line to try next time. Do not schedule role-plays unless the user asks for that.

## Body, mind, spirit

One micro-practice a day, 2-10 minutes. Rotate: a walk, stretching, breathing, a gratitude line, 10 minutes without a phone, reading a page.

## Rules

- The user sets the pace. If they skip a week, restart gently.
- On hard days the plan shrinks: one small thing is a win.
- Keep the source material the user likes (a book, a post, a list of techniques) as the pool you draw from. "Save less. Apply more."
