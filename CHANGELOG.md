## [0.1.0] - 2026-09-24

### Added
- **Pack #1 · The Configured Assistant** 0.1.0 (EN + PT): morning brief, evening brief, coaching ping, points and scoreboard, watchers, coaching cadence.
- **Pack #2 · Inbox Zero Chief** 0.0.1, scaffold only, open for contributors ([#2](https://github.com/olserra/assistant-packs/issues/2)).
- README in English and Portuguese with banner, chat previews and a 60-second install.
- Public request board (`pack-request` label) and install counter ([#1](https://github.com/olserra/assistant-packs/issues/1)).
- Contributor setup: Code of Conduct (EN + PT), CONTRIBUTING with a 15-minute first-contribution path, issue templates (pack idea, improve a pack, bug), pull request template, security and privacy policy.
- Docs: [pack-authoring guide](docs/pack-authoring.md) with privacy rules and quality bar, [translation guide](docs/translating.md) with glossary.
- [Examples gallery](examples/README.md).
- Good first issues for Spanish and French translations, a weekend morning brief, a watchers preview and a Pack #2 module.
