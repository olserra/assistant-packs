# Morning brief

**When:** daily at the user's morning time (default 07:00).
**Goal:** the user knows what the day looks like outside and what matters inside it, in under a minute.

## Sections (each starts with an emoji header)

1. **☀️ Weather** - today's high/low in the user's unit and the rain chance by part of day for their city. One line, plus a nudge only if it changes plans ("umbrella after 16:00").
2. **💱 Markets** - only the numbers the user chose (e.g. one currency pair, one crypto asset), with the change since yesterday. Skip the section if they chose none.
3. **📰 News** - 2-3 headlines per chosen region (e.g. world, their country). One line each, factual, no opinion.
4. **🤖 Topic of interest** - 2-3 items a senior professional in the user's field should know today, each with a source link.
5. **🎯 Focus of the day** - three priorities pulled from their calendar, open commitments and last night's reflection. If the calendar is heavy, say which one to protect.
6. **🏋️ Micro-training** - today's 5-minute exercise for the skill they chose (see coaching-cadence.md), plus the technique of the week in one line.
7. **🧘 Body, mind, spirit** - one small practice (a 10-minute walk, 3 minutes of breathing, a gratitude line). Scale down on hard days.
8. **🔥 Streak** - current points streak and yesterday's score (see points-scoreboard.md).

## Rules

- Pull weather, markets and news live at send time. Never reuse yesterday's numbers.
- Keep headlines to facts you can link. Offer links; include them by default only for the topic section.
- If a source fails, say "markets unavailable this morning" rather than guessing.
- Omit any section the user turned off. Order can change on request.

## Example (shape only, values are illustrative)

```
☀️ Thu 24 Sep · 19°/27°, dry until evening, 60% rain after 20:00
💱 EUR/USD 1.09 (+0.2%) · BTC $61.2k (-1.1%)
📰 World: ... / Your country: ...
🤖 3 things worth knowing today: ... (links)
🎯 Focus: 1) ... 2) ... 3) ...
🏋️ Micro-training: 5-min objection drill. Technique of the week: two lists.
🧘 10-minute walk after lunch.
🔥 Streak: 6 days · yesterday 3/4
```
