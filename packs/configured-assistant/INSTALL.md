# Install · Instalar

## English - copy this into your assistant

```
Install the "Configured Assistant" pack. Read these instructions:
https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant/SKILL.md
and its modules in the references/ folder next to it
(morning-brief.md, evening-brief.md, accountability-ping.md, points-scoreboard.md, event-watchers.md, coaching-cadence.md).
Then run the setup interview, schedule the routines I approve, and show me a sample evening brief for tomorrow.
```

## Português - copia isto para o teu assistente

```
Instala o pack "Assistente Configurado". Lê estas instruções:
https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant-pt/SKILL.md
e os módulos na pasta references/ ao lado
(resumo-matinal.md, resumo-da-noite.md, lembrete-diario.md, placar-de-pontos.md, vigilantes.md, coaching.md).
Depois faz a entrevista de configuração, agenda as rotinas que eu aprovar e mostra-me um exemplo do resumo da noite de amanhã.
```

## Other ways · Outras formas

- **Skill folder:** copy `skills/configured-assistant/` (or `-pt`) into your assistant's skills directory. See [ADAPTERS.md](../../ADAPTERS.md).
- **No scheduler?** Every module works on demand: "run my morning brief" / "faz o meu resumo matinal".
