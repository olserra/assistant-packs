# 🤝 Contributing

## English

Assistant Packs is built by the people who use it. Whether you fix a typo, translate a module or publish a whole pack, you are a contributor and you get credited.

**New here?** Start with the 15-minute path below. Everyone who takes part agrees to our [Code of Conduct](CODE_OF_CONDUCT.md).

### 🌱 Your first contribution in 15 minutes

No coding, no installs. Only a GitHub account and a browser.

| Minute | Step |
|:------:|------|
| 0-2 | Open the [good first issues](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) and pick one. Comment **"I'll take this"**. |
| 2-4 | Open the file named in the issue on GitHub and click the ✏️ pencil (or **Add file → Create new file** for a new one). GitHub offers to fork the repo for you: accept. |
| 4-12 | Make the change. Use the **Preview** tab to check it. Keep the structure of the file you're editing. |
| 12-14 | Scroll down, write a short title (e.g. *"Spanish: morning brief module"*) and click **Propose changes**. |
| 14-15 | Click **Create pull request**. The template asks four quick questions; tick the privacy box. Done. |

A maintainer reviews within a few days. If we ask for a change, edit the same file in your fork and the PR updates by itself. When it's merged, add yourself to [CONTRIBUTORS.md](CONTRIBUTORS.md), or we'll do it for you.

> [!TIP]
> Stuck? Comment on the issue or ask in [Discussions → Q&A](https://github.com/olserra/assistant-packs/discussions/categories/q-a). No question is too small.

### Ways to help, from quickest to biggest

1. **👍 Vote.** React on the [pack requests](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Apack-request+sort%3Areactions-%2B1-desc) you want. The most-voted gets built next. Installed a pack? 👍 [issue #1](https://github.com/olserra/assistant-packs/issues/1), the install counter.
2. **💡 Request a pack.** [Describe a routine](https://github.com/olserra/assistant-packs/issues/new?template=pack-request.yml) you wish your Instinct ran.
3. **🎉 Show your setup.** Post how you tuned a pack in [Show & Tell](https://github.com/olserra/assistant-packs/discussions/categories/show-and-tell). The best tips go into the pack pages and the [examples gallery](examples/README.md).
4. **🐞 Report a problem.** [Something doesn't work?](https://github.com/olserra/assistant-packs/issues/new?template=bug.yml)
5. **🌍 Translate.** Spanish, French and more. See the [translation guide](docs/translating.md) and the [`translation` issues](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Atranslation).
6. **🛠️ Improve a module.** A clearer rule, a better example, a new variant. [Suggest it](https://github.com/olserra/assistant-packs/issues/new?template=improve-pack.yml) or open a PR.
7. **📦 Build a pack.** Help finish [Pack #2 · Inbox Zero Chief](packs/inbox-zero-chief/) ([issue #2](https://github.com/olserra/assistant-packs/issues/2)) or publish your own. Read the [pack-authoring guide](docs/pack-authoring.md) first.

### Ground rules

- **Privacy is non-negotiable.** No real names, places, accounts, phone numbers, emails or sensitive details, anywhere. The full rules are in the [authoring guide](docs/pack-authoring.md#privacy-rules). Found personal data? [Report it privately](https://github.com/olserra/assistant-packs/security/advisories/new).
- **Safe by default.** Packs never send, book, buy or delete without the user's yes.
- **Small PRs.** One module or one fix per PR is easiest to review.
- **Say how you tested it.** "I ran it on my Instinct" is enough.

### Credits

Everyone is credited. Contributors appear in [CONTRIBUTORS.md](CONTRIBUTORS.md) and in the README (following the [all-contributors](https://allcontributors.org) spec, which counts translations, ideas, reviews and docs, not only code). Pack authors are listed in `pack.yaml` and on the pack page.

### How decisions are made

- What gets built next: the most-voted [pack request](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Apack-request+sort%3Areactions-%2B1-desc).
- Changes to how the project works: proposed in [Discussions → Ideas](https://github.com/olserra/assistant-packs/discussions/categories/ideas), discussed in the open.
- Regular contributors are invited to become maintainers.

## Português

O Assistant Packs é feito por quem o usa. Quer corrijas uma gralha, traduzas um módulo ou publiques um pack inteiro, és contribuidor e ficas nos créditos.

**Primeira vez?** Começa pelo caminho de 15 minutos abaixo. Quem participa aceita o nosso [Código de Conduta](CODE_OF_CONDUCT.pt.md).

### 🌱 A tua primeira contribuição em 15 minutos

Sem programação, sem instalar nada. Só uma conta GitHub e um browser.

| Minuto | Passo |
|:------:|-------|
| 0-2 | Abre as [boas primeiras issues](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) e escolhe uma. Comenta **"fico com esta"**. |
| 2-4 | Abre no GitHub o ficheiro indicado na issue e clica no lápis ✏️ (ou **Add file → Create new file** para um novo). O GitHub oferece-se para fazer o fork: aceita. |
| 4-12 | Faz a alteração. Usa o separador **Preview** para confirmar. Mantém a estrutura do ficheiro. |
| 12-14 | Desce, escreve um título curto (ex.: *"Espanhol: módulo resumo da manhã"*) e clica em **Propose changes**. |
| 14-15 | Clica em **Create pull request**. O modelo faz quatro perguntas rápidas; marca a caixa de privacidade. Feito. |

Um maintainer revê em poucos dias. Se pedirmos uma alteração, edita o mesmo ficheiro no teu fork e o PR atualiza-se sozinho. Depois do merge, acrescenta-te ao [CONTRIBUTORS.md](CONTRIBUTORS.md), ou fazemos nós.

> [!TIP]
> Encravaste? Comenta na issue ou pergunta em [Discussions → Q&A](https://github.com/olserra/assistant-packs/discussions/categories/q-a). Nenhuma pergunta é pequena demais.

### Formas de ajudar, da mais rápida à maior

1. **👍 Votar.** Reage aos [pedidos de packs](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Apack-request+sort%3Areactions-%2B1-desc) que queres. O mais votado é o próximo a ser construído. Instalaste um pack? Dá 👍 na [issue #1](https://github.com/olserra/assistant-packs/issues/1), o contador de instalações.
2. **💡 Pedir um pack.** [Descreve uma rotina](https://github.com/olserra/assistant-packs/issues/new?template=pack-request.yml) que gostavas que o teu Instinct fizesse.
3. **🎉 Mostrar a tua configuração.** Publica como ajustaste um pack em [Show & Tell](https://github.com/olserra/assistant-packs/discussions/categories/show-and-tell). As melhores dicas entram nas páginas dos packs e na [galeria de exemplos](examples/README.pt.md).
4. **🐞 Reportar um problema.** [Algo não funciona?](https://github.com/olserra/assistant-packs/issues/new?template=bug.yml)
5. **🌍 Traduzir.** Espanhol, francês e mais. Vê o [guia de tradução](docs/translating.pt.md) e as [issues `translation`](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Atranslation).
6. **🛠️ Melhorar um módulo.** Uma regra mais clara, um exemplo melhor, uma variante nova. [Sugere](https://github.com/olserra/assistant-packs/issues/new?template=improve-pack.yml) ou abre um PR.
7. **📦 Construir um pack.** Ajuda a terminar o [Pack n.º 2 · Chefe da Caixa de Entrada](packs/inbox-zero-chief/README.pt.md) ([issue #2](https://github.com/olserra/assistant-packs/issues/2)) ou publica o teu. Lê primeiro o [guia para criar packs](docs/pack-authoring.pt.md).

### Regras básicas

- **A privacidade não se negocia.** Sem nomes reais, lugares, contas, telefones, emails ou detalhes sensíveis, em lado nenhum. As regras completas estão no [guia](docs/pack-authoring.pt.md#regras-de-privacidade). Encontraste dados pessoais? [Reporta em privado](https://github.com/olserra/assistant-packs/security/advisories/new).
- **Seguro por defeito.** Os packs nunca enviam, reservam, compram ou apagam sem o sim do utilizador.
- **PRs pequenos.** Um módulo ou uma correção por PR é o mais fácil de rever.
- **Diz como testaste.** "Corri no meu Instinct" chega.

### Créditos

Toda a gente fica nos créditos. Os contribuidores aparecem no [CONTRIBUTORS.md](CONTRIBUTORS.md) e no README (seguindo a especificação [all-contributors](https://allcontributors.org), que conta traduções, ideias, revisões e documentação, não só código). Os autores de packs aparecem no `pack.yaml` e na página do pack.

### Como se decide

- O que se constrói a seguir: o [pedido de pack](https://github.com/olserra/assistant-packs/issues?q=is%3Aissue+is%3Aopen+label%3Apack-request+sort%3Areactions-%2B1-desc) mais votado.
- Mudanças na forma como o projeto funciona: propostas em [Discussions → Ideas](https://github.com/olserra/assistant-packs/discussions/categories/ideas), discutidas em aberto.
- Quem contribui com regularidade é convidado a ser maintainer.
