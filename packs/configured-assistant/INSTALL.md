# ⚡ Install · Instalar

Copy one block and send it to your Instinct, wherever you already talk to it.
Copia um bloco e envia ao teu Instinct, onde já falas com ele.

## 🇬🇧 English

### The whole pack (recommended)

```text
Install the "Configured Assistant" pack from Assistant Packs.
Instructions: https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant/SKILL.md
Modules are in the references/ folder next to it.
Run the setup interview with me, schedule only the routines I approve,
and show me a sample evening brief for tomorrow before the first one goes out.
```

### Just one module

```text
From the "Configured Assistant" pack, install only the morning brief module:
https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant/references/morning-brief.md
Ask me the setup questions it needs, then show me a sample for tomorrow.
```

Swap the file name for another module: `evening-brief.md`, `accountability-ping.md`, `points-scoreboard.md`, `event-watchers.md`, `coaching-cadence.md`.

### After install

| Say | What happens |
|-----|--------------|
| *"show me tomorrow's evening brief now"* | Check the format before the first scheduled one |
| *"move the morning brief to 6:30"* | Changes the time, keeps everything else |
| *"pause everything this week"* | Nothing scheduled until you say so |
| *"update the Configured Assistant pack"* | Re-reads the latest version and keeps your answers |
| *"remove the Configured Assistant pack"* | Stops the routines |

## 🇵🇹 Português

### O pack completo (recomendado)

```text
Instala o pack "Assistente Configurado" do Assistant Packs.
Instruções: https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant-pt/SKILL.md
Os módulos estão na pasta references/ ao lado.
Faz a entrevista de configuração comigo, agenda só as rotinas que eu aprovar
e mostra-me um exemplo do resumo da noite de amanhã antes do primeiro sair.
```

### Só um módulo

```text
Do pack "Assistente Configurado", instala só o módulo do resumo matinal:
https://raw.githubusercontent.com/olserra/assistant-packs/main/packs/configured-assistant/skills/configured-assistant-pt/references/resumo-matinal.md
Faz-me as perguntas de configuração de que precisa e mostra-me um exemplo para amanhã.
```

Troca o nome do ficheiro por outro módulo: `resumo-da-noite.md`, `lembrete-diario.md`, `placar-de-pontos.md`, `vigilantes.md`, `coaching.md`.

### Depois de instalar

| Diz | O que acontece |
|-----|----------------|
| *"mostra-me já o resumo da noite de amanhã"* | Vês o formato antes do primeiro agendado |
| *"passa o resumo matinal para as 6:30"* | Muda a hora e mantém o resto |
| *"pausa tudo esta semana"* | Nada agendado até dizeres |
| *"atualiza o pack Assistente Configurado"* | Relê a versão mais recente e mantém as tuas respostas |
| *"remove o pack Assistente Configurado"* | Para as rotinas |
